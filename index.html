My Projects

Movie Recommendation System

The Movie Recommendation System is a Machine Learning project designed to recommend movies based on user preferences and movie similarity. The system analyzes movie information such as genres, keywords, and other features to identify similar movies and provide personalized recommendations. It uses Python, Pandas, NumPy, and Scikit-learn to process movie data and calculate similarity between movies. The application is developed using Streamlit, providing a simple and interactive user interface where users can select a movie and discover five similar movie recommendations. This project helped me understand data preprocessing, feature extraction, similarity calculations, and the practical implementation of Machine Learning algorithms. The main objective of this project is to make movie discovery easier and provide users with relevant movie suggestions based on their interests.

Credit Scoring Model

The Credit Scoring Model is a Machine Learning project that predicts a customer's creditworthiness based on financial and personal data. This project helped me understand data preprocessing, model training, classification, and performance evaluation.
